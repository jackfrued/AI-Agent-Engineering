## LangGraph 快速上手指南

大语言模型（LLM）最初的使用方式非常简单：输入 Prompt，模型返回 Answer。这种模式适合问答、文本生成、翻译、摘要等一次性交互任务。但随着 AI 应用不断演进，人们希望模型能够完成越来越复杂的任务。例如，读取项目代码、调用数据库、访问 Web、执行 Shell 命令、编写代码、运行测试、修复错误，甚至与其他 Agent 协同工作。这些任务已经不再是一次 Prompt 就能完成，而是需要经历**规划（Plan）→ 执行（Execute）→ 观察（Observe）→ 决策（Decide）→ 再执行（Execute）**的多轮循环。

换句话说，AI 不再只是一个"回答问题的模型"，而逐渐演变成一个能够自主完成任务的 **Agent（智能体）**。然而，一个真正可用的 Agent 并不仅仅是"模型 + Prompt"这么简单，它通常还需要具备以下能力：

- 状态（State）：记录任务当前进展和上下文。
- 工作流（Workflow）：按照既定流程组织多个步骤。
- 工具调用（Tool Calling）：访问数据库、搜索引擎、Shell、API 等外部能力。
- 记忆（Memory）：保存长期或短期信息，避免每轮都从零开始。
- 人机协作（Human-in-the-Loop）：关键节点允许人工确认或干预。
- 持久化（Checkpoint）：支持中断恢复、失败重试和任务回放。
- 多 Agent 协同（Multi-Agent）：多个智能体分工合作，共同完成复杂任务。

如果仅依靠 Prompt 拼接这些能力，系统很快就会变得难以维护：上下文越来越长，逻辑越来越复杂，状态管理混乱，流程也难以扩展。因此，我们需要一种专门用于构建 Agent 工作流的框架，LangGraph 正是在这样的背景下诞生的。

### 1 核心概念

在 LangGraph 中，一切皆为**图 (Graph)**。图由**状态 (State)**、**节点 (Nodes)** 和**边 (Edges)** 组成。

#### 1.1 State（状态机的大脑）

`State` 是整个图唯一的真相来源，它定义了数据如何在各个节点之间流转。每次节点返回一个字典时，LangGraph 会根据定义的类型去**更新**全局状态。默认情况下，新值会**覆盖 (Overwrite)** 旧值。如果你希望数据是**追加 (Append)** 举动（比如聊天历史记录、日志），必须显式使用 `Annotated` 和聚合函数（如 `operator.add`）。

```python
import operator
from typing import Annotated, TypedDict


# 错误示范：如果不加 Annotated，messages 每次都会被后一个节点完全覆盖
class BadState(TypedDict):
    messages: list[str]


# 正确示范：使用 operator.add 实现增量追加
class CoreState(TypedDict):
    # 每次节点返回 ["新消息"]，都会被 append 到列表中，而不是替换
    messages: Annotated[list[str], operator.add]
    current_task: str
    retry_count: int
```

#### 1.2 Nodes（纯粹的执行单元）

`Node` 本质上是一个普通的同步或异步 Python 函数。

- **输入**：当前图的 `State`。
- **输出**：一个 `dict`，包含你需要**更新**的 State 字段。
- **底层细节**：节点内不要直接修改传入的 `state` 对象（视其为不可变对象）。只返回需要变动的键值对即可。

```python
async def research_node(state: CoreState) -> dict:
    print(f"正在处理任务: {state['current_task']}")
    
    # 模拟工具调用或 LLM 输出
    new_message = f"研究节点：找到了关于 {state['current_task']} 的核心数据。"
    
    # 只返回需要更新的字段，LangGraph 会自动合入全局 State
    return {
        "messages": [new_message], 
        "retry_count": state["retry_count"] + 1
    }
```

#### 1.3 Edges（控制流的管道）

边决定了从一个节点执行完后，下一步去哪里。LangGraph 区分两种边：

##### 3.1 普通边 (Normal Edge)

确定性的硬编码连线。

```python
from langgraph.graph import StateGraph, START, END

builder = StateGraph(CoreState)
builder.add_node("research", research_node)

# 从起点直接进入 research 节点
builder.add_edge(START, "research")
```

##### 3.2 条件边 (Conditional Edge)

动态路由。根据当前 `State` 的状态，决定下一步走向。条件边需要一个**路由函数 (Router Function)**。该函数接收 `State`，返回一个字符串（分支标签）。同时需要一个映射字典（`path_map`），将标签映射到真实的节点名称或 `END`。

```python
# 1. 路由函数
def route_after_research(state: CoreState) -> str:
    if state["retry_count"] >= 3:
        return "stop"
    return "continue"


# 2. 绑定条件边
builder.add_conditional_edges(
    "research",                  # 从哪个节点出来
    route_after_research,        # 路由判断函数
    {
        "stop": END,             # 满足 stop，直接结束整个图
        "continue": "research"   # 满足 continue，再次回到 research 节点（构成循环）
    }
)
```

#### 1.4 Checkpointer（状态持久化与记忆）

`Checkpointer` 是 LangGraph 实现断点续传、多轮对话记忆、人工介入（Human-in-the-loop）的灵魂组件。

- **底层细节**：当你给图编译时注入 `checkpointer`（如 `MemorySaver`），图在每个节点执行完毕后，都会自动将当前 `State` 的快照序列化保存。
- **线程隔离**：调用图时，**必须**在 `config` 中传入 `thread_id`。相同 `thread_id` 会共享、继承历史状态；不同 `thread_id` 完全隔离。

```python
from langgraph.checkpoint.memory import MemorySaver

# 实例化一个内存版持久化器
memory = MemorySaver()

# 编译图时注入
graph = builder.compile(checkpointer=memory)

# 执行时必须带上 config
config = {"configurable": {"thread_id": "user_session_001"}}
await graph.ainvoke({"current_task": "量子计算", "retry_count": 0}, config=config)
```

#### 1.5 案例：带重试控制的翻译 Agent

这个极简案例完整演示了 **State 追加、节点定义、条件边路由、持久化记忆**。

```python
from typing import TypedDict

from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import StateGraph, START, END


# 1. 定义状态
class AgentState(TypedDict):
    original_string: str
    translated_text: str
    iteration_count: int
    score: int


# 2. 定义节点（翻译节点）
def translate_node(state: AgentState):
    print('--- 正在翻译 ---')
    # 模拟翻译动作
    return {
        'translated_text': 'hello, world!',
        'iteration_count': state.get('iteration_count', 0) + 1
    }


# 2. 定义节点（检查节点）
def check_node(state: AgentState):
    print('--- 正在质检 ---')
    # 模拟评估：第一轮 50 分，第二轮 90 分
    score = 90 if state['iteration_count'] > 1 else 50
    return {'score': score}


# 3. 定义路由函数
def decide_next(state: AgentState):
    if state['score'] < 80:
        return 'loop'
    return 'done'


# 4. 构建图
workflow = StateGraph(AgentState)
workflow.add_node('translator', translate_node)
workflow.add_node('checker', check_node)

workflow.add_edge(START, 'translator')
workflow.add_edge('translator', 'checker')

workflow.add_conditional_edges(
    'checker',
    decide_next,
    {
        'loop': 'translator',  # 分数不够重试
        'done': END  # 分数达标结束
    }
)

# 5. 编译并运行
app = workflow.compile(checkpointer=MemorySaver())
config = {'configurable': {'thread_id': 'user_session_001'}}
initial_state = {'original_string': '你好，世界！', 'iteration_count': 0}

app.invoke(initial_state, config)

# 6. 检查历史
for history in app.get_state_history(config):
    print(history)
```

下面，我们引入 LLM 来实现翻译和评审，通过修改节点的代码让它们真正的运转起来，完整的代码如下所示。代码中使用了两个模型，一个用于翻译，一个用于评审，两个节点都设计为异步函数（更符合工程化需求），调用模型的时候使用了 `await chain.ainvoke()` 的方式。作为程序入口的 `main` 函数也设计为异步函数，通过 `asyncio.run(main())` 的方式进行调用。对异步 I/O（协作式并发）不熟悉的小伙伴可以自行查阅资料或者翻阅一下我的《从零开始学 Python》专栏。

```python
import asyncio
from typing import TypedDict, Any

from dotenv import load_dotenv
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langgraph.constants import START, END
from langgraph.graph import StateGraph


class AgentState(TypedDict):
    original_string: str
    translated_string: str
    is_good_enough: bool
    iteration_count: int


def create_translate_node(llm):

    async def translate_node(data: AgentState) -> dict[str, Any]:
        """翻译节点"""
        print('====== 正在翻译 ======')

        prompt = ChatPromptTemplate.from_messages([
            ('system', '你是一个专业的英文翻译助手'),
            ('user', '请翻译下面的内容:\n{sentence}'),
        ])
        chain = prompt | llm | StrOutputParser()
        result = await chain.ainvoke({'sentence': data['original_string']})
        return {
            'translated_string': result,
            'iteration_count': data.get('iteration_count', 0) + 1,
        }

    return translate_node


def create_review_node(llm):

    async def review_node(data: AgentState) -> dict[str, Any]:
        """评审节点"""
        print('====== 正在评审 ======')

        prompt = (f'请评判下面的翻译是否专业且地道，只需要回复 YES 或 NO\n'
                  f'原文: {data["original_string"]}\n'
                  f'译文: {data["translated_string"]}')
        chain = llm | StrOutputParser()
        result = await chain.ainvoke(prompt)
        return {'is_good_enough': 'YES' in result.upper()}

    return review_node


def decide_next(data: AgentState) -> str:
    """条件边决策"""
    if not data['is_good_enough'] and data['iteration_count'] < 3:
        return 'translator'
    return END


async def main():
    """程序入口"""
    load_dotenv()

    translate_llm = ChatOpenAI(
        base_url='https://api.deepseek.com',
        model='deepseek-v4-flash',
        temperature=0.8,
        max_tokens=512,
    )
    review_llm = ChatOpenAI(
        base_url='https://api.deepseek.com',
        model='deepseek-v4-pro',
        temperature=0.1,
        max_tokens=256,
    )

    # 创建工作流（状态图）
    workflow = StateGraph(AgentState)
    # 添加节点
    workflow.add_node('translator', create_translate_node(translate_llm))
    workflow.add_node('reviewer', create_review_node(review_llm))
    # 添加边
    workflow.add_edge(START, 'translator')
    workflow.add_edge('translator', 'reviewer')
    # 添加条件边
    workflow.add_conditional_edges('reviewer', decide_next)

    # 编译工作流（构建 Agent）
    agent = workflow.compile()
    # 将工作流绘制成 PNG 图片
    # agent.get_graph().draw_png('workflow.png')

    sentence = input('请输入要翻译的内容: ')
    state = AgentState(original_string=sentence, iteration_count=0)
    result = await agent.ainvoke(state)
    print(result)


if __name__ == '__main__':
    asyncio.run(main())
```

### 2 综合案例

LangGraph 的一大优势是内置了对高级 Agent 模式的支持：

- **Human-In-The-Loop（人机协作）**：通过 Checkpointer 机制，LangGraph 可以在关键节点（如执行敏感操作前）暂停工作流，等待人类审批或修改后再继续执行。
- **状态持久化与恢复**：支持在任意节点保存状态快照（持久化的 checkpointer），即使程序崩溃或网络中断，也可以从上一个检查点无缝恢复，这对于长时运行的任务极为重要。
- **Reflection（反思机制）**：允许在图中构建反馈循环，让 Agent 能够评估自己的输出并进行自我修正，从而提升生成内容的可靠性。

接下来我们实现一个自动生成和测试代码的 Agent，同时引入人机协作的工作模式，通过这个案例将上面的知识点串联起来，构建一个具有**代码生成、静态纠错、单元测试、人工审计、中断重启**的闭环 Agent。

#### 2.1 业务流拓扑图说明

案例的工作流如下图所示。

```
       [ START ]
           │
           ▼
   ┌───────────────┐
   │  coder_node   │◄──────────────┐
   └───────┬───────┘               │
           │                       │
           ▼                       │
   ┌───────────────┐               │
   │  tester_node  │               │ (如果测试失败且未超限)
   └───────┬───────┘               │
           │                       │
           ▼                       │
   ┌───────────────┐               │
   │  route result ├───────────────┘
   └───────┬───────┘
           │ (测试通过)
           ▼
     [ INTERRUPT ] (人工审核中断点)
           │
           ▼
   ┌───────────────┐
   │ router_human  ├───────────────┐
   └───────┬───────┘               │ (Rejected)
           │ (Approved)            │
           ▼                       ▼
       [ END ]             [ 修改代码或放弃 ]
```

#### 2.3 核心架构源码实现

```python
import asyncio
import sys
from typing import Annotated, TypedDict, Literal

from dotenv import load_dotenv
from langchain_core.messages import BaseMessage, HumanMessage
from langchain_openai import ChatOpenAI
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import StateGraph, START, END, add_messages


# ==========================================
# 状态
# ==========================================
class PipelineState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]  # 历史消息
    source_code: str     # 生成代码
    test_code: str       # 测试代码
    error_logs: str      # 错误日志
    iterations: int      # 当前迭代次数
    max_iterations: int  # 最大迭代次数
    human_approval: str  # 人工审核结果


load_dotenv()
llm = ChatOpenAI(base_url='https://api.deepseek.com', model='deepseek-v4-flash', temperature=0.2)


# ==========================================
# 节点
# ==========================================
async def coder_node(state: PipelineState) -> dict:
    print('\n[Node: Coder] 开始编写/修复代码...')
    messages = state['messages']
    iterations = state['iterations']

    if state['error_logs'] and state['source_code']:
        prompt = (
            f'上一次你生成的代码运行失败了。\n'
            f'[历史代码]:\n```python\n{state["source_code"]}\n```\n'
            f'[报错执行日志]:\n{state["error_logs"]}\n'
            f'请针对性修复代码，只返回完好的 python 代码，不要有 Markdown 套壳。'
        )
        messages = messages + [HumanMessage(content=prompt)]

    response = await llm.ainvoke(messages)
    cleaned_code = response.content.replace('```python', '').replace('```', '').strip()
    return {
        'source_code': cleaned_code,
        'messages': [response],
        'iterations': iterations + 1
    }


async def tester_node(state: PipelineState) -> dict:
    print('[Node: Tester] 组装代码并执行自动单元测试...')
    full_script = f'{state['source_code']}\n\n{state['test_code']}'

    import io
    # 保存现场
    old_stdout, old_stderr = sys.stdout, sys.stderr
    sys.stdout = buffer_out = io.StringIO()
    sys.stderr = buffer_err = io.StringIO()

    error_msg = ''
    try:
        safe_globals = {
            '__builtins__': {
                'print': print,
                'int': int,
                'float': float,
                'str': str,
                'range': range
            }
        }
        safe_locals = {}
        # 调用内置函数执行 Python 代码
        exec(full_script, safe_globals, safe_locals)
    except Exception as e:
        import traceback
        error_msg = traceback.format_exc()
    finally:
        # 恢复现场
        sys.stdout, sys.stderr = old_stdout, old_stderr

    combined_logs = f'{buffer_out.getvalue()}\n{buffer_err.getvalue()}\n{error_msg}'.strip()

    if error_msg:
        print(f'自动测试未通过，检测到异常。')
        return {'error_logs': combined_logs}
    else:
        print('自动化单元测试全部顺利通过！')
        return {'error_logs': ''}


# dummy node
async def human_review_node(state: PipelineState) -> dict:
    """专用于承载人工审核。当图运行到这里时，会被 interrupt 拦截。"""
    print('[Node: Human] 正在等待人工审核数据注入...')
    return {}


# ==========================================
# 路由
# ==========================================
def decide_post_test_path(state: PipelineState) -> Literal['coder', 'human_review', 'fail_exit']:
    """测试完毕后：有错就自动循环，没错让人类审核"""
    if not state['error_logs']:
        print('-> 自动测试通过，提交人工审核。')
        return 'human_review'

    if state['iterations'] >= state['max_iterations']:
        print('-> 自动纠错达到上限，宣告终止。')
        return 'fail_exit'

    print(f'-> 测试失败，准备进入下一轮自动修复（当前第 {state["iterations"]} 次）。')
    return 'coder'


def decide_post_human_path(state: PipelineState) -> Literal['approve_end', 'back_to_coder', 'stay_pending']:
    """判定人工审核意见"""
    print(f'\n[路由检查] 当前人工审核状态为: {state["human_approval"]}')

    if state['human_approval'] == 'Approved':
        print('-> 审核通过，准备结项。')
        return 'approve_end'
    elif state['human_approval'] == 'Rejected':
        print('-> 审核未通过！退回给 Coder 节点重新修复。')
        # 被人类拒绝后，把错误日志设为人类意见，引导大模型修改
        return 'back_to_coder'
    else:
        print('-> 状态仍为 Pending，继续保持挂起等待...')
        return 'stay_pending'


async def main():
    # ==========================================
    # 状态图的组装与编译
    # ==========================================
    workflow = StateGraph(PipelineState)

    workflow.add_node('coder', coder_node)
    workflow.add_node('tester', tester_node)
    workflow.add_node('human_review', human_review_node)

    workflow.add_edge(START, 'coder')
    workflow.add_edge('coder', 'tester')

    workflow.add_conditional_edges(
        'tester',
        decide_post_test_path,
        {
            'coder': 'coder',
            'human_review': 'human_review',
            'fail_exit': END
        }
    )

    workflow.add_conditional_edges(
        'human_review',
        decide_post_human_path,
        {
            'approve_end': END,
            'back_to_coder': 'coder',
            'stay_pending': 'human_review'
        }
    )

    memory_saver = MemorySaver()
    app = workflow.compile(checkpointer=memory_saver, interrupt_before=['human_review'])

    config = {'configurable': {'thread_id': 'session_003'}}

    initial_input = {
        'messages': [
            HumanMessage(
                content='写一个函数 `get_reverse_even(nums)`，输入一个整数列表，过滤其中的偶数，并逆序返回。'
            )
        ],
        'source_code': '',
        'test_code': 'assert get_reverse_even([1, 2, 3, 4, 6]) == [6, 4, 2]\nprint("Test Passed!")',
        'error_logs': '',
        'iterations': 0,
        'max_iterations': 5,
        'human_approval': 'Pending'
    }

    is_first_run = True
    while True:
        if is_first_run:
            print('\n--- [系统] 启动 Agent 自动构建流程 ---')
            # 第一次运行需要传入初始输入
            async for event in app.astream(initial_input, config=config, stream_mode='updates'):
                pass
            is_first_run = False
        else:
            print('\n--- [系统] 恢复运行，Agent 开始根据人工反馈修复代码 ---')
            # 后续运行传入 None 恢复执行
            async for event in app.astream(None, config=config, stream_mode='updates'):
                pass

        # 获取当前运行终止后的最新状态
        current_state = await app.aget_state(config)

        # 检查图是否正常结束（当 next 为空时代表走到 END 结束了）
        if not current_state.next:
            print('\n任务顺利完成！图已正常结束。')
            print(f'最终沉淀的完好源码:\n{current_state.values.get("source_code")}')
            break

        # 如果图没结束，说明撞上了 interrupt_before=['human_review']，停在人工审核节点了
        print(f'\n[人工介入点] 图当前已挂起，停留在节点: {current_state.next}')
        print(f'大模型当前提交的代码为:\n{current_state.values.get("source_code")}')

        user_input = input('请输入审核意见 (1:通过 / 2:拒绝): ').strip()

        if user_input == '1':
            print('你选择了：通过 (Approved)')
            await app.aupdate_state(config, {'human_approval': 'Approved'}, as_node='human_review')
        else:
            print('你选择了：拒绝 (Rejected)')
            feedback = "变量名不够优美，请重新重构，增加中文注释！"  # 模拟人类反馈的拒绝原因
            await app.aupdate_state(
                config,
                {
                    'human_approval': 'Rejected',
                    'error_logs': f'人工审核驳回意见：{feedback}'
                },
                as_node='human_review'
            )


if __name__ == '__main__':
    asyncio.run(main())
```

### 3 避坑总结

1. **无限循环熔断**：任何带有 `Conditional Edge` 构成环状结构的图，**必须**在 `State` 中维护一个 `iterations`（或 `retry_count`）计数器，并在路由函数中进行上限拦截。否则一旦大模型陷入逻辑死胡同，会导致算力成本暴增。
2. **状态粒度隔离**：不要把几百 KB 的无关上下文全部丢进全局 `State` 里。全局 State 应该只存放需要跨节点路由判断的控制变量、以及最终输出的生成物。节点内的中间变量尽量在节点内部消化。
3. **内存快照清理**：`MemorySaver` 只适用于开发阶段与单机测试。在生产环境中，请接入官方的 `MongoSaver`、`PostgresSaver` 或者通过 Redis 实现持久化扩展，以应对节点崩溃后的高可用状态恢复。
